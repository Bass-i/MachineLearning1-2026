## Descripción

Repositorio de entregas del proyecto de la asignatura MCDI504. Contiene los
notebooks ejecutados y los informes de la Sumativa 1, Formativa 2 y Formativa 3.

Las actividades abordan progresivamente definición del problema, análisis
descriptivo, regresión y clasificación supervisada.

## Entregas

- **Sumativa 1:** definición y orientación de IrisFlow mediante el dataset Iris.
- **Formativa 2:** implementación y comparación inicial de modelos de regresión.
- **Formativa 3:** implementación de modelos de clasificación sobre Titanic,
  incluyendo KNN, árbol de decisión, SVM, Naive Bayes y redes neuronales.

## Estructura del repositorio

- `Sumativa 1/notebooks/F1_Definicion.ipynb`

- `Formativa 3/docs/MCDI504_S3_AVANCE_GRUPO5.pdf`
- `requirements.txt`: librerías necesarias para ejecutar el notebook.

## Ejecución

1. Clonar o descargar el repositorio.
2. Crear y activar un entorno virtual de Python.
3. Ejecutar `pip install -r requirements.txt`.
4. Abrir el notebook de la entrega correspondiente en Jupyter o PyCharm.
5. Ejecutar todas las celdas en orden.

Los datasets utilizados se cargan desde las librerías empleadas por cada
notebook, por lo que no se requiere almacenar archivos de datos sensibles.
